## 怎么逐行学

打开某一曲，不要先查每一个词。按这个顺序读每一行：

1. **谁在对谁说话。** 角色名是舞台提示，不是歌词。`COMPANY` 是合唱，`ENSEMBLE` 是群演。
2. **先还原口语。** 说唱里大量省字，见下一节对照表。把一行在心里读成完整英语，再翻译。
3. **找出主干。** 问：主语是谁，动词是什么，宾语是什么。Hamilton 喜欢把修饰语堆在动词前面，主干常常藏在一行的末尾。
4. **再看双关。** 这出剧的关键词几乎都有两层意思。只翻译字面，会漏掉剧情。
5. **最后查生词。** 本曲「单词」里没有的，到文末词汇表。

一句值得抄进生词本的标准：它有习惯用法、双关，或者一种你能在别的歌里再遇到的语法。

## 先认识这套英语

### 说唱缩写

| 剧本里 | 完整形式 | 意思 |
| --- | --- | --- |
| sittin', workin', throwin' | sitting, working, throwing | 把 `-ing` 的 g 吃掉，口语里极常见 |
| gonna | going to | 将要 |
| wanna | want to | 想要 |
| gotta | got to | 必须（= have to） |
| I'm 'a / I'mma | I'm going to | 我这就要 |
| 'em | them | 他们 / 它们 |
| ya | you / your | 你 / 你的 |
| cuz / 'cause | because | 因为 |
| prob'ly | probably | 大概 |
| ev'ry, hist'ry, fin'ly | every, history, finally | 省掉一个弱读音节 |
| didja | did you | 你有没有 |
| 'Zat | Is that | 是那样吗 |
| woulda / coulda | would have / could have | 本来会 / 本来能 |
| g'wan | go on | 去吧（常带不耐烦或驱赶） |
| 'til, 'tween, 'specially | until, between, especially | 省掉词头 |
| ain't | am not / is not / are not / has not | 不规范否定，歌词、口语里用，书面作业里不要用 |

`ain't` 和吃掉 g 是风格，不是「更地道的标准英语」。Burr 写信、Washington 演讲时会换回完整、正式的句子。注意谁在用哪一种英语。

### 四种说话方式

- **Hamilton：** 拉丁词根的大词和街头说唱叠在一起。他用句子的密度证明自己。
- **Burr：** 短句、法律措辞、把态度藏起来。`Talk less. Smile more.`
- **King George：** 用情歌口吻谈殖民。语法简单，威胁包在甜言蜜语里。
- **Seabury：** 十八世纪传单英语。`Hear ye`、`thee`、`Heed not`。Hamilton 故意用 `thee` 回敬他。

### 贯穿全剧的双关

这些词后面还会回来。第一次见到就记下两层意思。

| 词 | 字面 | 在剧里还指 |
| --- | --- | --- |
| shot /ʃɑːt/ | 开枪；一小杯酒 | 一次机会。`throw away my shot` = 浪费我这唯一的机会 |
| satisfied /ˈsætɪsfaɪd/ | 满意 | 决斗用语里的「荣誉已得到补偿」；Angelica 则是永远不会满足 |
| wait for it | 等一下，好戏在后面 | Burr 的人生策略：等待，不冒险 |
| the room where it happens | 事情发生的那个房间 | 权力真正被决定的密室 |
| story | 故事 | 谁掌握叙事，谁就被历史记住 |
| right-hand man | 得力助手 | 也呼应「坐在父亲右手边」的圣经说法 |
| blow us all away | 让我们惊叹 | 后来 Philip 的死让 `blow away`（开枪打飞）变成字面 |
| burn | 燃烧 | Eliza 爱情的炽热，也是她烧掉信件 |
| time | 时间 | 结尾几乎每句都落在 `time` 上：他一辈子觉得时间不够 |

### 反复出现的语法

**修辞问句。** `How does a bastard ... grow up to be a hero?` 说话人并不等回答。`How does` 后面是一个很长的主语，动词 `grow up` 被远远甩到后面。读的时候先跳过去找动词。

**手段用 `by + -ing`。** `got a lot farther by working a lot harder`：靠更拼命，才走得更远。`by` 这里不是「被」。

**`may` 表示「有可能，但愿」。** `I may not live to see our glory` 是可能性。`May you always be satisfied` 是祝愿，动词用原形，这是虚拟式的残留。

**平行堆叠。** `a lot farther / a lot harder / a lot smarter`；`I don't have your name. I don't have your titles. I don't have your land.` 同一句式重复，一次比一次重。

**书信套语。** `Dear Alexander` 开头，`I have the honor to be Your Obedient Servant` 结尾。十八世纪这是客套。Burr 和 Hamilton 用它下决斗战书，客套就变成冷冰冰的礼貌。
